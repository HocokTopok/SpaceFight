# Asset provenance

`planet_0.png` … `planet_4.png`, `nebula.png`: original artwork generated by
`tools/generate_assets.py` for this project. Released under CC0-1.0.
No assets are downloaded at runtime; regeneration only requires Python 3.

`Tuffy.ttf`: Tuffy font by Thatcher Ulrich, public domain (CC0), distributed with
SFML 3.0.2 examples. Source: https://github.com/SFML/SFML/blob/3.0.2/examples/asset_licenses.md
and http://tulrich.com/fonts/ .
