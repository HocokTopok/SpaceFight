## Выполнено локально

Среда: macOS / Apple Silicon, Apple Clang 21, CMake 4.4.5, C++23,
SFML 3.0.2, Debug и Release.

| Проверка | Результат |
|---|---|
| Сборка ядра без SFML | Успешно |
| Полная Debug-сборка | Успешно |
| Полная Release-сборка `.app` | Успешно |
| CTest `core`, `gameplay`, `network` в Release | 3/3 passed |
| Headless ASan + UBSan | 2/2 passed, ошибок не обнаружено |
| Графический запуск / создание окна | Успешно |
| `--ui-test` | Все шаги прошли; созданы 6 изображений |
| CMake install в отдельный временный каталог | `.app`, бинарник и ресурсы установлены |
| `git diff --check` | Ошибок пробелов нет |

Внешний FreeType выдаёт предупреждение о повторном определении `OS_CODE`;
сборка собственных исходников проходит без предупреждений.

## Что проверяют тесты

`core_tests`:

- Связность 100 карт, наличие всех пяти типов, одинаковые стартовые флоты.
- Вложенные Composite-группы, Factory Method и суммирование характеристик.
- Совместное действие нескольких Decorator-улучшений.

`game_tests`:

- Roundtrip снимка, усечённый/испорченный формат, лишние данные.
- Неверный номер хода и отрицательное количество кораблей в приказе.
- Права на планеты, наличие гиперлинии, резерв ресурсов без изменения мира.
- Ожидание обоих игроков, исследование, точное восстановление Memento.
- Захват нейтральной планеты, ничья при одновременной потере столиц, дефицит энергии.
- Зеркальные матчи одинаковых AI: совпадение ресурсов, кораблей и обороны сторон.
- Четыре разных матча AI, достижение победы и проверка save roundtrip после каждого хода.
- Запись и чтение сохранения с диска.

Результаты четырёх детерминированных матчей (seed 100–103, номер хода после разрешения):

| Aurora AI | Ember AI | Последний номер хода | Победитель |
|---|---|---:|---|
| Aggressive | Economic | 19 | Ember |
| Economic | Defensive | 19 | Aurora |
| Defensive | Scientific | 25 | Ember |
| Scientific | Aggressive | 24 | Aurora |

Это проверки работоспособности и отсутствия простой зависимости от стороны,
а не исследование соревновательного баланса.

`network_tests` запускает два независимых GameFacade и реальное TCP-соединение:
handshake, начальная синхронизация, пять одновременных ходов, одинаковые снимки,
доставка событий. Отдельный клиент проверяет атомарное отклонение пакета,
содержащего корректную стройку и попытку построить на чужой планете.
Размер `0xffffffff` отклоняется до выделения памяти под заявленный пакет.

`--ui-test` использует те же callbacks кнопок, выбор планеты и обработчик клавиш,
что интерактивная игра. Он проверяет: Mine → Fighter → SEND → Research →
Commit → Undo → Menu → Help. Не создаёт пользовательского автосохранения.
Это проверка обработчиков приложения, а не синтез событий операционной системы.

## Визуальная проверка

Просмотрены карта, главное меню, вкладка флота, дерево исследований, состояние
после хода и справка. Текст читается, панели и кнопки помещаются в окно 1440×900.
Два снимка включены в `docs/screenshots/`. Встроенный рендер поддерживает
масштабирование окна с сохранением пропорций.

CUA увидел нативное окно и снял главное меню, но попытки клика возвращали
`noWindowsAvailable`. Поэтому успешное прохождение OS-кликов не заявляется.

## Границы проверки

- Linux-сборка и GitHub Actions в этой сессии **не запускались**. Добавлен workflow
  Ubuntu 24.04 / macOS 15; Linux UI проверяется через Xvfb после запуска CI.
- LAN проверен на одном Mac через loopback, не между двумя физическими устройствами.
- При разрыве связи нет возобновления прежней LAN-сессии; это явно описано в README.
- Звук, локализация, внешняя серверная инфраструктура и соревновательный баланс
  не входят в реализованный набор требований.
